v1.2.0 2026-06-15

引用窗口全面增强 — 卡片编辑、数量修改、升级/分解/制造查询

✨ 新增功能

  • 引用窗口不再自动关闭：跳转到目标表后窗口保持打开，方便连续浏览多个引用
  • 卡片替换引用：点击替换按钮直接修改主表 ItemID，支持撤销
  • 卡片删除引用：删除引用的同时自动清零配对 Count 列，避免游戏编译报错
  • 卡片修改数量：直接修改关联的 Count 列数值，按配对规则自动定位
  • 卡片名称显示数量：引用卡片标题行显示配对数量（如「好用的鱼饵 X 10」）
  • 添加新引用：行有空位时显示添加按钮，一键写入新引用并自动设置 Count=1
  • 升级/分解/制造 Tab：引用窗口新增标签页，扫描物品在 ITEM_UPGRADE / ITEM_BREAKUP / ITEM_CREATE 中的材料关系

🔧 修复

  • 修复卡片编辑/删除后引用窗口不刷新的问题（之前需切行或重启窗口才能看到新值）

📦 下载说明

  • Self-Contained 版本（~51MB）：解压即用，无需安装运行时
  • Framework-Dependent 版本（~3MB）：需安装 .NET 10 Runtime
v1.1.0 2026-06-07

中等版本更新 — 多标签页架构 + 引用系统增强

✨ 新增功能

  • 多标签页架构：打开新表时不再替换当前标签页，改为「已开则切回 / 未开则新增」
  • 切换标签页时自动还原上次选中的行位置
  • 脏 tab（有未保存修改）切走时执行内存级自动保存，切回时恢复修改内容
  • 引用跳转新标签页：点击引用目标时，若目标表已打开则切回，否则新建标签页并自动定位到目标行
  • 分片表完整支持：引用系统支持 ITEM_1.ldt、ITEM_2.ldt 等分片表的精确定位与跳转
  • 正向引用图标竞态修复：使用 SemaphoreSlim 串行化 + RegisterLease 去重
  • 同 rowId 跳过防抖：相同行的重复引用请求自动跳过
  • 卡片序号徽章：24×24 圆角深蓝灰序号徽章，直观显示引用数量
  • 描述展开链接：描述超过 120 字符时显示「▶ 展开」/「▼ 收起」切换链接
  • 键盘导航：支持 F3 查找下一个引用、Enter 跳转、鼠标点击高亮
  • 软焦点机制：3 秒软焦点解决焦点判定 bug，支持自动滚动到当前卡片

🔧 修复

  • 修复引用跳转后 tab 标签未激活的问题
  • 修复空 tab 永远不加载数据的问题
  • 修复 PendingLocateRow 跨函数传递丢失的问题
  • 修复 ApplyParseResultOnUiThread 不消费定位请求的问题
  • 修复双击引用后引用窗口未自动关闭的问题

📦 下载说明

  • Self-Contained 版本（~51MB）：解压即用，无需安装运行时
  • Framework-Dependent 版本（~2MB）：需安装 .NET 10 Runtime
v1.0.1 2026-05-27

首个正式发布版本

✨ 新增功能

  • 表格编辑：打开、保存、撤销/重做、复制/粘贴
  • 查找与筛选：按关键词筛选，支持正则表达式
  • 批量替换：当前列查找与替换，支持预览
  • 批量填数：按递增或等比规则写入数值
  • 选图窗（Shift+A）：从 SPF 资源浏览图标
  • 物品预览（Shift+P）：实时显示说明与头图
  • 修改记录（Alt+S）：高亮已改单元格，可还原原值
  • 多编码支持：GBK / CP949 / UTF-8 自动择优
  • 文件关联：将 .ldt 默认用本程序打开
  • 繁体转简体：工具菜单一键将所有繁体中文转换为简体，支持撤销和修改记录
  • CSV 导入/导出：支持 UTF-8/GBK/CP949 编码，按列名匹配

🔧 修复

  • 修复查找栏(Ctrl+V)无法粘贴的问题
  • 修复网格粘贴总是报错的问题

📦 下载说明

  • Self-Contained 版本（~46MB）：解压即用，无需安装运行时
  • Framework-Dependent 版本（~2MB）：需安装 .NET 10 Runtime
