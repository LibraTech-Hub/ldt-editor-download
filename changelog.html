🎉 LDT Editor - 更新日志

查看每个版本的新功能、改进和修复

v1.2.2 2026-07-22

🚀 新增功能

  • 授权管理：加入基础版/标准版权限控制，可从帮助菜单导入和管理授权
  • 购买与升级入口：基础版可直接打开购买页面，授权成功后界面权限状态立即更新

✨ 改进

  • 图标加载加速：优先解析 SPF 尾部索引，并复用图集位图缓存，减少重复扫描和 PNG 解码
  • 选图窗响应优化：同一图集切换行时直接移动选框，避免重复读取 SPF，连续选图更流畅
  • 更新日志体验：改为在软件内通过 WebView2 展示更新日志

🔧 修复

  • 修复虚拟 _RowId 列导致的数据列错位问题
  • 修复部分表格行号识别错误及修改后物品预览未及时刷新的问题
  • 修复授权成功后按钮状态未同步，以及“立即购买”入口无法打开的问题
v1.2.1 2026-06-22

🚀 新增功能

  • 数据完整性增强：大幅提高 .ldt 文件保存后的数据完整性，解决特殊字符可能丢失的问题
  • 多编码支持优化：完善对韩文（CP949）、简体中文（GBK）等编码的支持，保存成功率从 71% 提升至 100%

✨ 改进

  • 优化文件保存逻辑，确保未修改的数据行保持原样
  • 改进特殊字符处理，避免保存时出现乱码或占位符
v1.2.0 2026-06-15

引用窗口增强

🚀 新增功能

  • 编辑引用：可以直接在引用卡片上替换、删除引用，或修改数量
  • 点击「🔄 替换」按钮可更换引用的物品
  • 点击「🗑️ 删除」按钮可删除引用（同时清空数量，避免数据错误）
  • 点击「🔢 修改数量」可调整物品数量
  • 添加引用：当前行有空位时，可以直接添加新引用（自动设置数量为 1）
  • 数量显示：引用卡片名称后显示数量，如「好用的鱼饵(1小时) X 10」
  • 配方查看：新增「升级/分解/制造」标签页，可以查看物品的合成配方和材料需求
  • 保持打开：跳转到引用目标后，引用窗口保持打开，方便连续查看

✨ 改进

  • 引用卡片编辑后立即刷新显示
  • 所有修改支持撤销（Ctrl+Z）
v1.2.0 2026-06-15

引用窗口全面增强 — 卡片编辑、数量修改、升级/分解/制造查询

✨ 新增功能

  • 引用窗口不再自动关闭：跳转到目标表后窗口保持打开，方便连续浏览多个引用
  • 卡片替换引用：点击替换按钮直接修改主表 ItemID，支持撤销
  • 卡片删除引用：删除引用的同时自动清零配对 Count 列，避免游戏编译报错
  • 卡片修改数量：直接修改关联的 Count 列数值，按配对规则自动定位
  • 卡片名称显示数量：引用卡片标题行显示配对数量（如「好用的鱼饵 X 10」）
  • 添加新引用：行有空位时显示添加按钮，一键写入新引用并自动设置 Count=1
  • 升级/分解/制造 Tab：引用窗口新增标签页，扫描物品在 ITEM_UPGRADE / ITEM_BREAKUP / ITEM_CREATE 中的材料关系

🔧 修复

  • 修复卡片编辑/删除后引用窗口不刷新的问题（之前需切行或重启窗口才能看到新值）

📦 下载说明

  • Self-Contained 版本（~51MB）：解压即用，无需安装运行时
  • Framework-Dependent 版本（~3MB）：需安装 .NET 10 Runtime
v1.1.0 2026-06-07

多标签页

🚀 新增功能

  • 多表同时打开：可以同时打开多个 .ldt 文件，每个文件显示在独立标签页中
  • 智能切换：打开已开启的文件时自动切换到对应标签页
  • 自动保存：切换标签页时自动保存未保存的修改到内存，避免数据丢失
  • 记忆位置：切换回标签页时自动恢复上次选中的行

🔗 引用系统增强

  • 新标签页跳转：点击引用目标时，在新标签页中打开并定位到目标行
  • 分片表支持：完整支持 ITEM_1.ldt、ITEM_2.ldt 等分片表的跳转
  • 图标显示优化：修复引用图标加载问题，显示更稳定

🎨 引用窗口优化

  • 序号徽章：显示引用序号，方便识别
  • 描述折叠：长描述自动折叠，点击「▶ 展开」查看完整内容
  • 键盘导航：支持 F3 查找下一个引用、Enter 跳转
  • 自动滚动：自动滚动到当前选中的引用卡片

🔧 修复

  • 修复引用跳转后标签页未激活的问题
  • 修复空标签页不加载数据的问题
v1.0.1 2026-05-30

CSV 导入/导出

🚀 新增功能

  • 导出 CSV：可以将表格导出为 CSV 文件（支持导出全部行或仅可见行）
  • 导入 CSV：可以从 CSV 文件导入数据（支持替换或追加模式）
  • 编码兼容：自动识别 UTF-8 / GBK / CP949 编码，导出的 CSV 可用 Excel 直接打开

✨ 繁体转简体

  • 一键转换：工具菜单新增「繁体转简体」功能，可以将表格中所有繁体中文转换为简体
  • 安全可靠：转换前确认，转换后可撤销（Ctrl+Z）

🔧 修复

  • 修复查找栏无法粘贴的问题（Ctrl+V）
  • 修复网格粘贴报错的问题
v1.0.1 2026-05-27

选图窗增强（Shift+A）

🚀 新增功能

  • 非模态窗口：选图窗保持打开，方便连续选择多个图标
  • 批量设置：选中多行时，双击图标可批量设置所有选中行的图标
  • 图集切换：支持下拉切换不同的图集序号，鼠标悬停时可用滚轮快速切换

📝 修改记录（Alt+S / Alt+Z）

  • 查看修改：按 Alt+S 高亮显示所有修改过的单元格
  • 查看原值：鼠标悬停在修改过的单元格上可查看原始值
  • 快速还原：按 Alt+Z 可还原鼠标悬停的单元格
  • 自动保存记录：可选择在保存文件时自动保存修改记录

🔍 功能菜单（Ctrl+F）

  • 查找与筛选：支持全列或当前列查找，可选区分大小写、正则表达式
  • 批量替换：在当前列进行查找替换，支持预览后再执行
  • 批量填数：按规则（递增/等比）批量填入数值，支持前缀/后缀、仅可见行
  • 内嵌查找条：按 Enter 或 F3 快速查找下一处，Ctrl+Enter 应用为行筛选

👁️ 物品预览（Shift+P）

  • 实时预览：根据当前行显示物品说明和图标
  • 快速编辑：双击状态值、名称、描述可直接编辑并写回表格

🌐 编码与多开

  • 自动编码识别：打开文件时自动识别 GBK、CP949、UTF-8 编码
  • 多开支持：同时运行多个程序时，非活动窗口自动释放全局热键，避免冲突

📖 帮助文档

  • 使用说明：帮助菜单中可查看完整的使用说明文档
