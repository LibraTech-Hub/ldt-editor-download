v1.5.0 2026-08-22

SPF 文件树、多表切换与状态续接

🚀 新增功能

  • SPF 文件树：打开 SPF 容器后在左侧浏览全部可解析 LDT，仅显示 LDT 条目，不再混入图片、音频等资源
  • 容器内多表切换：同一个 SPF 外层标签内直接切换 LDT，重复名称按稳定入口索引准确定位
  • 每表状态保留：独立保存各 LDT 的未保存修改、撤销/重做、筛选、编码显示和脏状态
  • 视图位置续接：切换标签或引用目标后恢复滚动位置、焦点单元格和选中行

✅ 改进与修复

  • SPF 引用检索：关系查询支持容器内存表，引用跳转不再依赖 SPF 文件名推断逻辑表
  • 修改记录安全性：SPF 条目修改记录按容器与入口独立存储，并校验文件身份和内容哈希
  • 发布安全门控：Release 继续移除内部写验证命令，并保持三文件 self-contained 发布布局
v1.4.4 2026-08-15

掉落概率编辑、奖池均分与关系抽屉优化

🚀 新增功能

  • 物品掉落概率编辑：显示外层概率、包内条件概率与最终掉落概率，并可按百分比调整支持写回的概率
  • 赌博奖池概率编辑：奖励卡片显示实际百分比，单击即可调整目标概率，并支持一键均分整个奖池
  • 统一浮动关系抽屉：MOBLOOT、物品选择与赌博奖池使用一致的浮动侧栏和拖拽调整方式
  • 分组浏览优化：补充全部展开、全部折叠与分组折叠控制，各文件标签页独立记忆检视器状态

✅ 改进与修复

  • MOBLOOT 刷新与删除：首次跳转立即刷新正确引用，删除直接掉落时同步清除物品 ID 与对应概率
  • 配方关系可靠性：恢复“编辑配方”入口，并隐藏包含缺失目标物品的整组无效配方
  • 概率安全写回：校验活动标签页、来源行、旧值与目标表，写回后刷新并定位实际目标行
  • 概率界面精简：赌博奖励仅显示实际百分比，单项修改与均分使用原子写回，编辑弹窗更紧凑
v1.4.3 2026-08-12

掉落组工作流、历史导航与怪物预览增强

🚀 新增功能

  • MOBLOOT 怪物预览：显示怪物名称、图标、经验、金币与地区声望等信息，同时保留掉落表字段的直接编辑能力
  • ITEMSET 掉落组工作流：浏览、选择和维护物品组；新增操作贴近目标分区，组标题可直接导航到对应数据
  • 分组历史与快速导航：记录最近访问的掉落组，支持返回历史组，并统一提供全部展开、全部折叠与分组折叠控制
  • 赌博包独立抽屉：将赌博包奖池放入独立抽屉，减少与常规关系内容混排，并记忆抽屉宽度

✅ 改进与修复

  • 分组加载提速：缓存 ITEMSET 分组目录，并在成员变化时增量刷新，减少重复扫描和等待
  • 状态防串页：切换预览、编辑引用或按 ID 导航时清理过期控件，仅允许最新请求更新界面
  • 操作层级优化：替换、删除和添加入口集中到组标题，物品卡片继续专注于查看和定位
v1.4.2 2026-08-10

配方关系编辑闭环与安全写回

🚀 新增功能

  • 配方关系直接编辑：在关系工作台中新增、替换或删除升级、分解和组合配方物品，并可修改材料数量
  • 完整配方槽位操作：支持添加主物品、材料和产物；卡片保留物品名称、图标与数量

✅ 改进与修复

  • 安全写回：按关系目录声明的真实来源字段写入，并校验当前表、行与旧值；上下文过期时阻止覆盖
  • 关系解析：补强升级、分解和组合配方的解析、分组与回归验证
  • 证据文档：补充 NPC 关系证据与规则说明，为关系目录扩展提供可核对依据

配方关系工作台、中文显示与 LDT 编码兼容

🚀 新增功能

  • 配方关系工作台：集中查看物品制作、升级和分解关系，材料、结果与需求展示更完整，支持直接定位来源
  • 数据一致性检查：检查无效引用、ID/数量不匹配、重复主键和异常文字，双击结果即可定位到对应单元格

  • 批量操作：批量替换可限定为当前选中行，降低误改未选中数据的风险

🔧 修复

  • 修复部分中文表格自动解码不稳定、编辑后可能保存为问号的问题，未修改的数据行继续保持原始字节
  • 修复多文件打开请求并发时可能覆盖活动标签页，以及拖放文件被 WebView2 当作下载的问题
  • 修复数据一致性检查结果定位后目标列可能不在视口内的问题，并增加目标单元格高亮

v1.2.0 2026-06-15

引用窗口增强

🚀 新增功能

  • 编辑引用：可以直接在引用卡片上替换、删除引用，或修改数量
  • 点击「🔄 替换」按钮可更换引用的物品
  • 点击「🗑️ 删除」按钮可删除引用（同时清空数量，避免数据错误）
  • 点击「🔢 修改数量」可调整物品数量
  • 添加引用：当前行有空位时，可以直接添加新引用（自动设置数量为 1）
  • 数量显示：引用卡片名称后显示数量，如「好用的鱼饵(1小时) X 10」
  • 配方查看：新增「升级/分解/制造」标签页，可以查看物品的合成配方和材料需求
  • 保持打开：跳转到引用目标后，引用窗口保持打开，方便连续查看

✨ 改进

  • 引用卡片编辑后立即刷新显示
  • 所有修改支持撤销（Ctrl+Z）

引用窗口全面增强 — 卡片编辑、数量修改、升级/分解/制造查询

✨ 新增功能

v1.0.1 2026-05-27

选图窗增强（Shift+A）

🚀 新增功能

  • 非模态窗口：选图窗保持打开，方便连续选择多个图标
  • 批量设置：选中多行时，双击图标可批量设置所有选中行的图标
  • 图集切换：支持下拉切换不同的图集序号，鼠标悬停时可用滚轮快速切换

📝 修改记录（Alt+S / Alt+Z）

  • 查看修改：按 Alt+S 高亮显示所有修改过的单元格
  • 查看原值：鼠标悬停在修改过的单元格上可查看原始值
  • 快速还原：按 Alt+Z 可还原鼠标悬停的单元格
  • 自动保存记录：可选择在保存文件时自动保存修改记录

🔍 功能菜单（Ctrl+F）

  • 查找与筛选：支持全列或当前列查找，可选区分大小写、正则表达式
  • 批量替换：在当前列进行查找替换，支持预览后再执行
  • 批量填数：按规则（递增/等比）批量填入数值，支持前缀/后缀、仅可见行
  • 内嵌查找条：按 Enter 或 F3 快速查找下一处，Ctrl+Enter 应用为行筛选

👁️ 物品预览（Shift+P）

  • 实时预览：根据当前行显示物品说明和图标
  • 快速编辑：双击状态值、名称、描述可直接编辑并写回表格

🌐 编码与多开

  • 自动编码识别：打开文件时自动识别 GBK、CP949、UTF-8 编码
  • 多开支持：同时运行多个程序时，非活动窗口自动释放全局热键，避免冲突

📖 帮助文档

  • 使用说明：帮助菜单中可查看完整的使用说明文档
